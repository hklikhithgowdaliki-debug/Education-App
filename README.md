# Education-App – KSEAB Papers

Android app (Flutter) with previous-year and model question papers for students in Karnataka:

| Board | Coverage | Source |
|---|---|---|
| Karnataka SSLC (10th) | All subjects, languages and vocational papers, main + supplementary, 2012 onwards | KSEAB papers via karnatakaboard.com |
| Karnataka 2nd PUC (12th) | Science, Commerce, Arts, languages, vocational – Exam 1/2/3 2024–2025 | dpue-exam.karnataka.gov.in |
| VTU Engineering | Model question papers for every branch, 2014–2025 schemes | vtu.ac.in |

Students browse **board → stream/branch → year/scheme → exam/semester**, search by subject or code,
read papers in the built-in PDF viewer and keep them offline.

## How the paper database works
- `data/sources/*.json` – one file per board, generated by the scripts in `tools/`.
- `data/catalog.json` – merged, de-duplicated catalog (also copied to `app/assets/catalog.json`).
- The app ships with the bundled catalog and on every launch downloads the latest
  `data/catalog.json` from the `main` branch of this repo, so **new papers reach users without an
  app update** – just regenerate and push.
- PDFs are downloaded from the publisher when a student opens them and cached on the device
  (verified as real PDFs before saving). They are not bundled in the APK, which keeps the app small
  (~4,000 papers would otherwise be several GB) and lets broken links be fixed server-side.

### Updating the catalog
```bash
python3 tools/build_vtu.py     # VTU engineering
python3 tools/build_puc.py     # 2nd PUC
python3 tools/build_sslc.py    # SSLC
python3 tools/check_links.py   # drop links that return 404 / non-PDF
python3 tools/build_catalog.py # merge -> data/catalog.json + app/assets/catalog.json
```
To add papers by hand, append entries to a file in `data/sources/` with the fields
`board, course, stream, group, semester, subject, code, year, type, url, source` and rerun
`build_catalog.py`.

## Building the app
Requires Flutter 3.27 and the Android SDK (API 34/35), Java 17.
```bash
cd app
flutter pub get
flutter test
flutter run                         # debug on a device/emulator
flutter build appbundle --release   # Play Store bundle
```
See [PLAY_STORE.md](PLAY_STORE.md) for signing and publishing, and
[PRIVACY_POLICY.md](PRIVACY_POLICY.md) for the privacy policy used in the store listing.

`python3 tools/make_icons.py` regenerates the launcher icons and store graphics.
